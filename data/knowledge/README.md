# 열차 대화 자료

example_lore.md는 사용자가 제공한 시나리오와 기획서의 인물별 사실이다. 각 fact 블록에는 ID, 말할 수 있는 NPC, 필요한 사건이 있다.

services/retriever.py는 현재 대화에서 엔진이 허용한 ID와 NPC·진행 조건을 먼저 제한한 뒤 최대 3개 자료를 반환한다. 이 작은 고정 세계관에는 외부 벡터 DB를 추가하지 않았다. 파일만 넣으면 자동 검색되는 구조라고 설명하지 않는다.

목적지·시도 횟수·기관사의 인식은 정해진 공개 시점을 따른다. 자료 조회는 정답 판정이 아니며 키워드가 검색됐다고 아이템을 지급하지 않는다. 이 폴더는 public 밖의 서버 전용 자료다.
