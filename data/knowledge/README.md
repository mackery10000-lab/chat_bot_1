# 열차 대화 자료

example_lore.md는 사용자가 제공한 시나리오와 기획서의 인물별 확정 사실이다. 각 fact 블록에는 ID, 말할 수 있는 NPC, 필요한 사건이 있다. character_profiles.json은 비진행 대화를 위한 인물별 말투·기본 지식·모르는 사실·허용된 즉흥 대화 범위를 담는다. 기본 프로필에는 잠긴 목적지·비밀번호·표 특징을 넣지 않는다.

services/retriever.py는 현재 대화에서 엔진이 허용한 ID와 NPC·진행 조건을 먼저 제한한 뒤 최대 3개 자료를 반환한다. 이 작은 고정 세계관에는 외부 벡터 DB를 추가하지 않았다. 파일만 넣으면 자동 검색되는 구조라고 설명하지 않는다.

목적지·시도 횟수·기관사의 인식은 정해진 공개 시점을 따른다. 자료 조회는 정답 판정이 아니며 키워드가 검색됐다고 아이템을 지급하지 않는다. 이 폴더는 public 밖의 서버 전용 자료다.

질문마다 lore·smalltalk·deflect·confusion 응답을 실제 모델로 구성할 수 있으나 그 대사가 새 조사 증거나 진행 상태가 되지는 않는다. 시나리오 진행 대화는 기존 서버 승인 대사를 사용한다. 자세한 기준은 [인물 자유 대화 규칙](../../docs/CHARACTER_CHAT.md)을 참고한다.
