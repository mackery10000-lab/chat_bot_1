# 현재 프로젝트의 실행과 배포 범위

기본 결과물은 Python 3.12·Flask 단일 앱을 로컬 VS Code에서 실행하는 ZIP이다. 로컬 접속 성공은 공개 인터넷 배포 완료를 뜻하지 않는다.

Dockerfile은 원본 경로를 유지하고 public의 이미지·폰트를 함께 복사한다. 현재 Compose는 기존 포트 5001과 개발용 파일 마운트를 유지하면서 /app/data에 이름 있는 볼륨을 사용하여 컨테이너 재생성 후 진행을 보존한다. knowledge와 images 하위 폴더는 기존 읽기 전용 마운트를 유지한다.

원본 .env는 Docker 이미지로 복사하지 않는다. Compose가 원본 환경에서 키·모델을 읽어 프로세스에 전달한다. 파일을 고치거나 새 환경 항목을 추가할 필요가 없다.

공개 서비스는 상태를 유지할 수 있는 디스크 또는 외부 저장소를 선택해야 한다. 임시 파일 시스템의 SQLite를 장기 저장으로 가정하지 않는다. 현재 기본 저장 방식은 로컬 또는 영속 디스크를 가진 단일 서비스에 맞춘 것이다. 여러 독립 서버의 로컬 DB를 자동 동기화하는 구현은 포함하지 않았다.

실제 배포 시 확인할 항목은 정적 자산 경로, 동일 출처 API, HTTPS와 쿠키, 지속 저장, 동시 요청과 외부 API 오류 처리다. 이번 ZIP은 새 공개 URL을 생성하거나 배포하지 않았다.
