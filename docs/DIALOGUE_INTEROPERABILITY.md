# 선택지와 자유대화 상호운용 검증

2026-11-12 첨부된 아키텍처 제안서를 현재 코드에 적용했다. 기준은 작업 시작 시의
커밋 `31a87be6b05de312affd4f983a3e63d41366be88`이다. 이전 문서의 검수 수치는
이번 실행 결과로 사용하지 않았다.

## 실행 계약

1. UI 행동은 기존 `apply_action`을 실행하며 의도 해석 모델을 호출하지 않는다.
2. 자유 입력의 의미 후보는 `generator.interpret`가 해석한다. 모델에게 제공하는
   맥락에는 현재 선택지의 실행 의미, 현재 단계와 직전 답변의 기대 대상만 추가한다.
3. `resolve_dialogue_route`는 실제 원문의 근거, 현재 선택지 여부, 질문과 실행의
   차이, 부정·가정·인용, 현재 인물과 대상을 검사한다. 상태를 바꾸지 않는다.
4. 검증된 현재 선택지는 `choose → _choose_scenario`를 실행한다. `effect`와 `next`를
   별도로 복제하지 않는다. 직접적인 기존 행동은 `apply_intent`의 동일한 소유·위치·
   열람 조건을 통과해야 한다. 미래 선택지의 실행 시도는 기존 409 오류를 유지한다.
5. 부정·가정·불명확한 입력은 인물이 되묻는다. 잡담이나 문서 조사 뒤의 짧은 동의는
   이전 의뢰를 수락하지 않으며, 의뢰 자체는 남아 있어 명시적인 발언으로 복귀할 수 있다.
6. `public_dialogue_facts`는 인물과 서버 플래그로 허용된 사실만 복사한다. 생성 대사는
   이미 공개된 사실을 그대로 되짚을 수 있으나 새 단서, 지급, 허가, 엔딩을 선언할 수 없다.

`DialogueRoute`의 COMMITTABLE은 기존 엔진에 전달할 수 있다는 뜻이며, 보상 지급이
확정됐다는 뜻이 아니다. NON_MUTATING과 CLARIFICATION_REQUIRED는 자유 응답 또는
재확인 경로다. 라우터에는 아이템·플래그·확인 토큰을 직접 변경하는 기능이 없다.

분류기의 보정과 서비스 경계의 재검증은 같은 순수 함수를 사용한다. 두 번 검증해도
결과가 같음을 검사하며, 별도의 모델 호출이나 두 번째 상태 기계를 추가하지 않는다.

## 유지한 내용

- 장소·동선, 아이템 ID, 인물 설정, 시나리오 JSON, 지식 원문, 이미지·영상·퍼즐 UI.
- Flask API의 입력과 최상위 응답 필드, SQLite 스키마와 요청 예약·원자적 커밋.
- 요청 ID 재전송, revision 충돌, 소유·열람·원본 반환, 마지막 확인 토큰과 입력 기회.
- 노인 증언 전 청소원 분실물 분기 차단, 한 설명에서 같은 표의 두 특징 확인,
  부분 특징의 비누적 처리, 화장실과 기관실 대화 분리, 삭제했던 선택지·창문 상호작용.
- 기존 저장 기록은 필수 신규 필드나 초기화 없이 읽으며 직전 대화 맥락은 이력에서 계산.

`tests/fixtures/dialogue_preservation.json`은 세계관·화면 파일 11개와 저장·이동·
아이템·열람·퍼즐·최종 확인을 담당하는 코드 16개의 기준 지문이다. 텍스트의 줄바꿈은
플랫폼 차이를 허용하고, 실행 코드는 AST로 비교한다. 본 작업에서 이 계약은 바꾸지 않았다.

## 검사 방법과 기준 보정

수정 전 전체 검사에서는 256개를 실행해 실패 41건과 import 오류 등을 포함한 오류
3건을 기록했다. 하위 테스트의 여러 실패가 포함되므로 실패 건수와 테스트 수는 다르다.
기존 테스트를 삭제하거나 skip하지 않고 누락된 런타임 계약을 구현했다.

오래된 기대값과 모의 입력은 다음 범위에서 바로잡았다.

- 탐험가가 실종 사건을 배경 대사로 공개할 때도 신문과 사건 공개 플래그가 같은 사건에서
  처리되어야 한다. 인물의 원래 대사·말투는 유지한다. 일반적인 정차 질문은 사건 소개와 구분한다.
- 증거 보관함은 기존 UI처럼 현재 연도 주장 뒤에 제공한다. 연도 주장은 `year_claimed`만
  바꾸며, `year_proven`·조작 권한·시도 횟수는 증거의 최종 확인 전까지 바뀌지 않는다.
- 생성 실패·스포일러 차단 시험의 모의 분류 결과에도 실제 입력과 일치하는 `quote`를
  넣는다. 원문에 없는 근거를 주입하는 경우는 별도의 재확인 검사로 검증한다.

추가 검사는 200회 교차 대화, 현재 ID에 잘못 대응한 무관한 질문, 문서·화장실·직업
질문 뒤의 짧은 동의, 저장 복구, 보상 요청 재전송, 읽기 전용 라우팅과 코드 보존을 포함한다.
브라우저에서는 화면 크기별 선택지·입력·저장 복구와 함께 신문·도구 지급, 부분 표 설명,
표 반환, 화장실 요청, 잡담 뒤 동의와 명시적인 의뢰 수락을 실제 UI로 실행한다.

```powershell
.\runtime\python.exe -B -X utf8 -m unittest discover -s tests -q
node tools/check_dialogue_ui.mjs
```

모든 검사는 임시 게임 저장소와 모의 모델을 사용한다. 실제 플레이 저장 기록과 `.env`를
수정하지 않는다. 유료 API를 사용하는 실모델 한국어 의미·자연스러움 검수는 실행하지 않았다.
