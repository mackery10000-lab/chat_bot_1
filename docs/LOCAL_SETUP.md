# 로컬 실행과 문제 해결

현재 제품의 단일 PowerShell 실행 블록은 루트 README에 있다. app.py·requirements.txt·원본 .env가 있는 프로젝트 폴더를 VS Code로 열고 Python 3.12 가상환경 또는 Conda로 실행한다.

PowerShell 활성화 정책에 막히면 활성화하지 않고 .venv/Scripts/python.exe를 직접 사용한다. py -3.12가 없으면 Python 3.12를 설치하거나 Conda 경로를 사용한다. 기존 프로젝트에 vendor 폴더나 다른 시작 파일이 있다고 가정하지 않는다.

기본 주소는 http://127.0.0.1:5000/ 이다. 포트 충돌은 현재 터미널의 PORT 변수로 바꾼다. .env를 수정하지 않는다. 같은 서버를 여러 터미널에서 중복 실행하지 않는다.

화면이 뜨는데 AI 응답이 실패하면 원본 환경과 외부 서비스의 인증·사용 한도·연결을 확인한다. 모델 오류는 게임 오답이 아니며 해당 턴의 상태와 마지막 시도는 보존된다. 화면의 같은 요청 다시 시도 또는 기록 불러오기를 사용한다.

진행은 data/train_state.sqlite3와 브라우저 쿠키로 복구된다. 새 게임은 화면에서 명시적으로 시작한다. 저장소 파일을 임의로 덮어쓰지 않는다. 다른 작업 디렉터리에서 서버를 실행해도 내부 경로는 app.py 기준으로 계산한다.

한글 글꼴과 모든 게임 자산은 public 안에 포함되어 있다. 모델 연결을 제외한 정적 화면은 외부 폰트 CDN을 요구하지 않는다.

검사는 python -m unittest discover -s tests -v로 실행한다. 자동 검사에는 실제 API 과금이 없으며 실제 모델 품질은 별도 검수한다.
