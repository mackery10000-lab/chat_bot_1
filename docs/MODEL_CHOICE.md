# 기존 모델 설정 유지

이번 환경 연결판은 원본 `.env`의 `OPENAI_MODEL=gpt-4o-mini`를 그대로 사용합니다. 키와 모델 값을 바꾸지 않았고 환경 파일에 새 항목을 추가하지 않았습니다.

현재 요청은 `reasoning` 또는 `reasoning_effort`를 포함하지 않습니다. 원본 환경의 두 변수만으로 실행되도록 연결했습니다. 기존 모델을 다른 모델로 강제 교체하지 않습니다.

새 기획을 검증할 때는 캐릭터 설정 유지, 근거 없는 답변, 응답 시간 등을 같은 대표 질문으로 확인합니다. 이번 작업의 목적은 기존 환경과 원본 베이스의 연결이며 모델 교체가 아닙니다.

실제 API 검수와 외부 호출 없는 자동 검사는 구분합니다. 연결 상세는 [모델 연결 가이드](MODEL_SETUP.md)를 참고하세요.
