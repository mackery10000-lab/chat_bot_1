# 차창·노인·미니맵 수정 완료

- 차창: 종이 패널 대신 기존 객차와 어울리는 나무 창틀·커튼 안에서 영상을 재생한다. PC·모바일에서 원본 비율을 유지하고 닫을 때 재생 자원을 해제한다. [이미지와 생성 기록](../public/assets/images/ui/WINDOW_PROMPT.md).
- 노인: 승인된 `elder-seated-v4.png`와 다리 방향을 유지하고 쿠션 중앙으로 이동했다. 배치 `[860,495,380,570]`와 클릭 윤곽이 일치하며 다른 인물·배경은 그대로다.
- 미니맵: 기존 `train-route-six-cars.png`를 유지한다. 종이와 나무 연결부만 다듬고 종이가 축 뒤로 말리는 동작을 적용했다. 연속 클릭·화면 회전·움직임 줄이기 설정을 처리하고, 지도 펼침이 장면 크기를 바꾸지 않는다.
- 임시 저장 복원 과정의 JavaScript 충돌을 해결했다. 해금 중 접기 방향을 바꿔도 펼침 완료 후 강조가 시작되도록 보정했다. 실행기·런타임·`.env`와 게임 진행 규칙은 이번 재개 작업에서 수정하지 않았다.

최종 검증: PC·모바일 6개 화면 크기의 [차창·미니맵 검사 113개](../.local/gameplay-ui-qa/1794188335693/result.json), 관련 서버 검사 6개 통과. 브라우저 예외·자산 요청 실패는 0건이다. JavaScript 구문 검사와 Git 변경 형식 검사도 통과했다.
