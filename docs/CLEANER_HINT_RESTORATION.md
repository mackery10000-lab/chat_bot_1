# 청소원 외형 설명 단계의 강조 복구 — 2026-11-12

노인에게 다시 물어본 뒤 청소원에게 돌아오면 기존 설명 선택지는 복원되지만
보관함과 증언 이미지의 빛이 꺼져 있던 문제를 수정했다.

## 원인과 변경

인물을 바꿀 때 `pending_dialogue`를 비우는 기존 규칙은 정상적으로 작동했다.
그러나 `testimony_hint`는 이 값만 확인했고, 저장된 청소원의 시나리오 단계
`describe`를 확인하지 않았다. 따라서 다시 대화하거나 새로고침했을 때
설명을 기다리는 선택지가 있어도 강조가 표시되지 않았다.

`GameEngine.public`의 표시 값이 현재 설명 단계도 확인하도록 수정했다.
게임 진행 중인 밝은 3호차에서, 노인 외형 증언을 실제로 얻어 보관하고 있고,
청소원과 외형 설명·재확인 단계에 있을 때만 강조한다. 응답 값은 항상 boolean이다.

기존 PNG 윤곽의 따뜻한 빛과 움직임 줄이기 설정의 정적인 빛을 그대로 사용한다.
보관함 버튼, 증언 목록과 상세 보기, 확인한 문장의 붉은 강조도 유지한다.
승차권을 찾거나 대화를 끝내면 빛을 끈다.

표시를 복원하기 위해 대화 의무나 특징을 저장하지 않는다. 노인 증언 선행 조건,
한 번의 설명에서 두 특징 확인, 부분 설명의 서로 다른 종이 지급, 물건 열람·반환,
기존 자유대화·선택지 처리와 다른 진행 조건은 변경하지 않았다.

## 회귀 검사

- `tests/test_requested_ui.py`: 선택지로 설명 시작 → 노인 재방문 → 청소원 복귀 →
  새로고침 → 설명 입력 선택 → 증언 열람 → 대화 종료·재개 → 실제 승차권 획득.
  수정 전에는 청소원 복귀 지점에서 강조가 꺼지는 실패를 재현했다.
- 같은 테스트에서 선행 증언·소유·조명·위치·현재 인물·게임 종료·승차권 획득 조건과
  화면 조회가 저장 상태를 바꾸지 않는 것도 확인한다.
- `tools/check_dialogue_ui.mjs`: 실제 데스크톱·모바일 화면에서 위 흐름과 보관함·증언
  윤곽 광원, 두 특징 강조, 움직임 줄이기 설정, 부분·완성 설명 후 광원을 확인한다.

유료 API 호출 없이 임시 저장소와 모의 모델을 사용한다.
