# 인물 설정 반영

기준: 2026-11-02 사용자가 제공한 「게임 시작 → 1호차 → …」 텍스트.
적용 범위는 인물의 성격, 말투, 배경, 보유 정보와 대화 반응이다.

| 인물 | 적용한 특징 |
| --- | --- |
| 탐험가 | 호기심으로 2026년에 탑승. 유쾌하고 계속 호의적인 존댓말. 수첩에 장소·시간을 기록해 반복 확인. 다른 승객들의 불신. 낡은 바닥 붕괴로 발목 부상. |
| 노인 | 초기 기억 장애, 약간 까탈스러움, 부산 말투와 “아이고”. 정중한 인사에는 어디로 가는지 묻기. 2016년 인식, 2026년은 농담. 모르는 것은 기억이 안 난다고 응답. |
| 청소원 | 차분하고 무던한 서비스 응대와 완곡한 청유형. 노인이 쏟은 커피 청소. 2016년 인식. 반복 질문에는 비켜달라고 부탁하며 응대는 계속함. |
| 승무원 | 불안을 숨기는 방어적인 격식체. 긴 운행과 멈춘 시계의 이상은 인정. 도움을 받으면 감사하고 표정·말투가 부드러워짐. 보고서를 처음부터 들고 있는 묘사 제거. |
| 기관사 | 신중하고 권위적이며 냉정한 격식체. 이미 반복을 알고 제동·경로 확인을 시도함. 위험 구간에 신중하게 반대. 기존 증거 확인 후 시간 경과에 놀라고 협조. |

자유 입력에서도 탑승 동기·직업·부상·위험 경고에 답한다. 무례·재촉은 실제 폭력과 구분하며 함께 묻는 정보나 외형 설명을 무시하지 않는다.

## 지식의 경계

- 세계관의 사실과 각 인물이 알고 있는 사실을 구분한다. 버뮤다 삼각지대의 실종 설정은 배경으로 기록하되, 이를 모르는 노인이나 청소원의 증언으로 만들지 않는다.
- 원문에 없는 가족·구체적인 부산 추억·여행 목적·실종 원인을 만들어내지 않는다.
- 현재 연도를 묻는 질문과 “2026년이다”라는 주장을 구분한다.
- 탐험가가 목적지나 제어 해법을 알려주거나, 노인·청소원이 시간의 경과를 아는 대사를 추가하지 않는다.
- 기존 증언·아이템·보고서 공개 조건에 따라 허용된 정보만 전달한다.

## 적용하지 않은 부분

이 텍스트의 엔딩, 최종 탈출 규칙, 정답 인정 범위, 입력 기회, 자동 정차·하차 판정은 반영하지 않았다. 기존 시나리오 노드의 연결과 효과, 아이템 획득·반환 조건, 장치·출입 조건을 유지한다. 인벤토리 문서와 이미지도 변경하지 않았다.

검증: `tests/test_characters.py`에서 배경 대화의 진행 상태 보존, 인물별 시간 인식과 반응, 재촉 이후 질문 처리, 반복 질문 뒤 승차권 지급, 도움 전후 승무원 태도와 출입 조건, 기관사의 증거 전후 반응을 검사한다. 기존 회귀 검사에서 모든 GOOD/BAD 경로와 아이템·장치 조건을 함께 확인한다.
