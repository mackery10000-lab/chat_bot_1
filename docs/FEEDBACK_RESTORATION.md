## 복원한 동작

- 두루마리 지도 접기·펼치기, 접힘 상태 저장, 접힌 상태에서 현재 칸 표시. 대화를 시작하면 자동으로 접고 끝내면 원래 상태로 복귀한다. 플레이어가 직접 접은 지도는 대화 후에도 접혀 있다.
- 잠긴 칸의 이름·상태·툴팁을 숨기고 해당 객차를 어둡게 표시한다. 접근성 이름도 미공개 칸 이름 대신 “아직 열리지 않은 칸”을 사용한다. 진행 조건으로 새로 열린 칸은 이름을 표시한다.
- 힌트 요청 전의 반짝임, 새 이동 가능 칸의 네 번 강조. 대화·문서·영상이 가린 동안 새 칸 강조를 보류한다. 운영체제의 모션 감소 설정을 존중한다.
- 화면과 대화 장면에 맞춘 아이콘·문자 크기, 대화 입력부 정렬, 내레이션 구분. `“산”이었는데` 같은 인용 단어는 전체 대사의 일부로 표시한다.
- 인트로 건너뛰기. GOOD/BAD 엔딩 영상은 기존 완료 흐름을 유지한다. 차창 영상에는 재생 컨트롤을 표시하지 않는다.
- 노인의 표 외형 증언을 듣기 전 청소원의 선택지는 노인에게 먼저 말을 걸도록 연결한다. 탐색 중에는 대화 선택지를 표시하지 않고, 대화 중에 시나리오 선택지를 표시한다.
- 연도 증거 확인 후 기관사의 수긍 대사를 먼저 보여준다. 이후 플레이어가 “마지막 한 번을 직접 입력해 보겠습니다.”를 선택해 제어판을 연다.
- 22:00 출발·23:59 실종·2016.11.13 신문, 2026년 현재 승차권을 대사·문서 데이터·PNG 기록물·탑승 화면에 반영한다. 과거 신문을 제출하면 소지한 2026년 승차권과 대조한다.

## 함께 유지한 변경

[인물 대화 규칙](CHARACTER_CHAT.md)의 동적 답변, 진행 규칙과의 분리, 인물별 지식 경계, 무관한 질문 회피, 설정 변경 요구에 대한 혼란 응답을 유지한다. 인물 프로필과 세계관 문서에도 복원된 시간 설정을 반영했다.

[장소 상호작용 정의](SCENE_INTERACTIONS.md)의 네 원본 배경, 호차별 인물 배치, 원본 크기에 맞춘 클릭 윤곽, 손전등, 문·보고서·레버·분기기 연결을 유지한다. 네 배경은 제공한 PNG와 SHA-256이 계속 일치한다.

원격 변경 27개 파일을 대조했다. 19개는 요청한 최종 트리와 내용이 같고, 8개는 현재 변경과 함께 병합했다. 비교 자료와 작업 전 백업은 `.local/feedback-restore/`에 있다. 기존 저장 데이터와 환경 파일은 수정하지 않는다.
