# 시작·발권·안내문 화면 수정

- 시작 문구: “평범한 출장길이었다. 적어도, 그 열차에 오르기 전까지는...”
- 발권 아래 안내: “저희 열차에 탑승해 주셔서 감사합니다.” 이름 검증과 발권 중·완료 표시는 유지한다.
- 시작 화면 승차권과 발권 화면: `01호차`, `08C`.
- 1호차 안내문: 원본 배경과 클릭 윤곽을 유지하며 글자 영역만 배경·호버 양쪽에서 흐리게 표시한다. 클릭하면 기존 안내문 원본을 반투명 검정 배경 위에 직접 표시한다.
- 탐험가: 최초 만남과 다시 말을 거는 경우 모두 “안녕하세요.”로 인사를 시작한다. 선택지와 진행 효과는 유지한다.
- 새 조사: 설정과 엔딩에서 최초 화면으로 돌아간다. 기존 게임 연결·이름·인트로 재생 표식만 해제하고 이름 입력과 발권을 다시 거친다. 음량·음소거·지도·움직임 설정은 유지한다.
- 시작 화면: 기존 제목 로고·글자·주요 배치를 유지하고 전등·간판·사운드·설정 이미지를 교체했다. 왼쪽 등은 꺼지고 가운데 등은 약 5초 주기로 유리·주변광이 함께 깜빡이며 오른쪽 등은 계속 켜진다.
- 간판: 수평으로 시작해 500ms 후 왼쪽 지지선이 늘어나고 관성에 따라 흔들린 뒤 기울어진 상태로 멈춘다. 실제 그림의 고리에 줄 끝을 맞추며 화면 크기가 바뀌어도 연결을 유지한다. 움직임 줄이기 설정에서는 정지한다.
- 발권 화면: 기존 글자·입력란·구조·크기를 유지하며 전등·금속 발권기·표의 종이·잉크 얼룩·버튼 표면을 교체했다. 저장된 화면 효과 설정을 이어받는다.

새 래스터 이미지는 내장 `image_gen`으로 생성·편집했다. 프로젝트 저장 위치는 `public/assets/start/images/entry-*.png`이며, [파일별 최종 프롬프트와 참조 이미지](../public/assets/start/images/ENTRY_PROMPTS.md)를 기록했다. 조명·줄 연결·입력·버튼·글자는 브라우저에서 실제로 동작한다.

기존 노인 이미지와 배치 레이어, 미니맵 이미지·조명·말림 CSS, 차창 프레임과 실행기의 해시는 작업 전후 동일하다. [보존 비교](../.local/entry-refinement/preserved.json).

## 최종 검증

- Python 회귀 검사 198개 통과. 진행·대화·퍼즐·엔딩·새 조사 초기화 검사를 포함한다.
- [PC·모바일 브라우저 검사 99개](../.local/gameplay-ui-qa/1794287680012/result.json) 통과. 1440×900, 390×844, 320×568, 844×390에서 화면 배치와 조작을 확인했다. JavaScript 예외와 자산·API 요청 실패는 0건이다.
- 간판 초기 수평·500ms 후 처짐·감쇠 흔들림·고리 연결과 실제 5초 조명 변화를 확인했다. 효과 끄기와 시스템 움직임 줄이기, 발권 화면의 설정 유지도 검사했다.
- 안내문 배경·호버 흐림과 클릭 후 해금, 탐험가의 두 인사 경로, 초기화 취소·확정, 이름 재입력·인트로·엔딩 후 최초 화면 복귀를 확인했다.
- 생성 이미지의 원본과 프롬프트를 보관했다. 별도로 픽셀을 검사해 전등 3개가 모두 실제 캡처에 그려져 있음을 확인했으며, 미리보기 현상에 대한 앱 우회 수정은 추가하지 않았다.

## 후속 보정: 사용하지 않는 안내문과 낡은 간판 줄

2·3호차에서만 안내문 자리를 주변과 연결되는 목재 벽으로 복원했다. 내장 `image_gen`으로 만든 `public/assets/images/scenes/passenger-wall-repaired.png`의 작은 벽 영역만 부드럽게 합성하며, 1호차의 원본 안내문과 클릭 기능은 유지한다. [편집 프롬프트와 적용 범위](../public/assets/images/scenes/WALL_REPAIR_PROMPT.md).

간판은 수평으로 시작해 500ms 후 왼쪽 줄이 미세하고 불규칙하게 떨리며 버틴다. 짧게 걸렸다 풀리는 움직임을 거쳐 약 2.2도 기울어진 상태로 멈추며 큰 진자 흔들림은 제거했다. 낡은 줄의 가는 섬유도 줄과 함께 움직인다. 고정점 연결, 화면 크기 변경, 움직임 줄이기와 애니메이션 종료 후 자원 정리는 유지한다.

후속 검증: [시작·발권 검사 101개](../.local/gameplay-ui-qa/1794288468711/result.json), [장면·인물·문·손전등 검사 245개](../.local/gameplay-ui-qa/1794288572099/result.json), 관련 서버 검사 6개 통과. 브라우저 예외와 자산 요청 실패는 0건이다. 원본 배경·안내문, 인물·문 등록, 노인·청소원·탐험가 이미지, 미니맵과 차창 자산, 진행 로직의 [해시 보존 비교](../.local/wall-sign-refinement/scope-check.json)도 확인했다.
