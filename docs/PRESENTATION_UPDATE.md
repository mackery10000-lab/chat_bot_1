# 제어 장치·엔딩·노인·로딩 화면 수정

제어 장치의 종이 테두리를 제거하고 기존 어두운 장치 창으로 복원했다. 숫자 다이얼, 도착역 입력, 레버, 최종 확인과 남은 기회 처리는 기존 퍼즐과 서버 판정을 그대로 사용한다.

엔딩은 종이 이미지를 원본 3:2 비율로 통째로 표시한다. 상단 기차 도장이 늘어나지 않으며 제목·본문·재시작 버튼은 기존 게임 폰트의 HTML이다. 해피 엔딩은 따뜻한 종이, 새드 엔딩은 채도를 낮춘 잿빛 종이와 밝은 글씨를 사용한다. 새드 엔딩 이미지의 찢김과 작은 구멍에는 실제 투명도가 있다. 영상 종료와 재시작 연결은 유지한다.

노인의 탐색용 이미지는 옆으로 앉은 자세로 다시 생성했다. 오른쪽 좌석에 골반과 허벅지를 놓고 발을 통로 바닥 쪽으로 내렸다. 배치는 원본 객차 좌표 `[700,500,410,565]`이며 기존 앞좌석 가림과 새 접촉 그림자를 적용했다. 인물 윤곽으로 클릭 영역을 다시 생성해 청소원·걸레와 겹치지 않게 했다. 대화용 초상화는 그대로 사용한다.

생성에 사용한 내장 `image_gen` 도구, 프로젝트 저장 경로와 최종 프롬프트는 [종이 이미지 기록](../public/assets/images/ui/PANEL_PROMPTS.md)과 [노인 이미지 기록](../public/assets/images/characters/README.md)에 있다. CLI 이미지 생성은 사용하지 않았다.

## 로딩 화면

검정 화면 아래쪽의 세계관 문구와 오른쪽 아래 눈·톱니 표시를 사용한다. 화면 전체를 기준으로 배치하며 모바일 세로·가로 화면, PC, 화면 안전 영역과 동작 줄이기 설정에 대응한다.

`POST /api/loading-text`는 현재 설정된 OpenAI 모델로 짧은 한국어 분위기 문장을 생성한다. 고정 공개 배경, 현재 공간의 종류와 조명만 사용하며, 반복 풍경은 이미 관찰한 경우에만 전달한다. 플레이어 이름·대화·소지품·정답·확인 토큰을 전달하지 않는다. 생성 문구를 게임 엔진이나 저장 처리에 넣지 않는다.

생성 요청은 장면 로딩과 독립적으로 실행된다. 8초 모델 제한, 중복 요청 억제와 세션별 15초 캐시를 적용했다. 실패하거나 검증을 통과하지 못한 문장은 마지막 안전한 문구로 대체한다. AI를 기다리기 위해 게임 화면을 붙잡지 않는다. 기존 Responses 호출 방식과 설정을 재사용했다. 구현 시 [Responses API 공식 문서](https://developers.openai.com/api/reference/python/resources/responses/methods/create)와 [Python SDK 공식 문서](https://developers.openai.com/api/reference/python)를 확인했다.

실제 연결에서도 다음 문구가 AI 생성 결과로 반환되는 것을 확인했다.

> 희미한 조명이 낡은 좌석과 무거운 커튼을 비추고, 차창에는 밤의 어둠이 고요히 번집니다.
