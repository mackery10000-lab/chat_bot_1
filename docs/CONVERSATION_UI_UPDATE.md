# 대화 기록 및 진행 화면 보완 · 2026-11-12

기존 캐릭터 원화의 얼굴을 원형 프로필로 표시하고, 전체 대화 기록을 말풍선으로 다시 볼 수 있게 했다. 후속 요청에 따라 미니맵의 객차 위 원형 아이콘만 제거했다. 객차 그림과 클릭 좌표, 잠금 표시는 유지한다.

## 적용 내용

- 가로 화면: 우측 여백의 중앙에 전체 대화 기록을 배치한다. 별도의 상단 제목·설명은 없으며, NPC의 얼굴·이름과 왼쪽 말풍선, 사용자의 오른쪽 말풍선을 표시한다. 기존 기록장 이미지를 어둡게 조정해 창 배경에 낡은 종이 질감을 더했다. 위쪽 기록을 읽을 때 스크롤 위치를 유지하고 새 대화로 이동하는 버튼을 제공한다.
- 세로 화면: 기존 장면과 입력창 배치를 유지하며 JOURNAL에서 같은 말풍선과 얼굴 프로필로 전체 기록을 확인한다.
- 오래된 대화는 `history_archive`에 보관한다. 시나리오와 AI가 참조하는 `history`의 기존 240개 제한은 유지한다. 기존 저장 기록도 별도 초기화 없이 이어진다. 이전 버전에서 이미 삭제된 기록은 복원할 수 없다.
- 칸 이동 중에도 기존 검은 배경, 로딩 문구, 우측 하단 톱니바퀴를 사용한다. 이동 중 입력 차단과 최소 표시 시간은 유지한다.
- 청소원에게 분실물 특징을 설명하거나 설명을 확인하는 단계에서만 증언 힌트를 표시한다. 보관함은 해당 소지품이 있는 페이지로 열리며 페이지 이동도 가능하다. 증언의 이미 확인한 문장 안에서 ‘바랜 종이’, ‘구멍’을 붉은 밑줄과 굵은 글씨로 강조한다.
- 소지품 행동 버튼은 기존 빈 종이 버튼 배경과 공통 로컬 UI 글꼴을 사용한다. 버튼에 포함돼 있던 이미지 글씨를 실제 텍스트로 바꿨다.
- 새 칸 개방 시 대화 중에도 안내도를 자동으로 펼친다. 문서를 보고 있는 동안에는 창을 닫은 뒤 표시한다. 사용자가 저장한 접힘 설정은 자동 펼침으로 덮어쓰지 않는다.
- 안내도는 Web Animations API가 없는 환경에서 프레임 기반 애니메이션을 사용하며, 완료 신호가 누락되는 환경에서는 타이머로 상태와 입력 잠금을 정리한다. 명시적인 움직임 줄이기 설정은 유지한다.
- 도착역 입력은 공통 UI 글꼴과 가운데 정렬을 사용한다.
- 시작 문장은 OS의 움직임 줄이기 설정에서도 순차적으로 나타난다. 스크립트가 실행되지 않을 때는 HTML의 전체 문장이 남는다.
- 엔딩 영상의 정상 종료, 재생 오류, 진행 정지 모두 결과창에 도달하도록 보완했다. 오프닝 영상의 재생 오류도 게임 진입을 막지 않는다.
- 구형 열차 시설 안내서를 읽기 전에는 승무원실 출입문, 점검 덮개, 손잡이 조사점을 표시하지 않는다. 서버의 기존 조작 조건도 유지한다.
- 기존 고운바탕 대사 글꼴을 라이선스와 함께 로컬에 포함해 외부 폰트 서버 의존성을 제거했다.
- 청소원 설명 단계에서는 인벤토리 버튼과 증언 이미지의 투명 윤곽을 따라 따뜻한 빛이 퍼진다. 목록·상세 보기에도 적용하며, 움직임 줄이기 설정에서는 정적인 빛을 유지한다. 사각 테두리 강조는 사용하지 않는다.

## 미니맵 이미지

내장 imagegen으로 원형 아이콘과 지지대를 제거한 `public/assets/images/ui/train-route-no-icons.png`를 만들었다. `train-map-medallions.svg`의 여섯 마스크 안에서만 편집본을 표시한다. 나머지 픽셀은 원본 `train-route-six-cars.png` 및 기존 소등 이미지에서 표시한다.

사용 프롬프트: “Remove all six circular black-and-brass medallions above the car roofs, including their supporting posts. Seamlessly reconstruct the parchment, mountain and forest landscape. Preserve the original framing, carriages, roofs, windows, wheels, rails, lighting and colors; no new text or symbols.”
