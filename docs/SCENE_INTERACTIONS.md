# 장소 배경과 상호작용 정의

좌표의 기준 파일은 `config/scene_layout.json`이다. 배경 경로·실제 PNG 크기·문 윤곽·조사 대상·인물 배치를 원본 픽셀로 정의한다. `tools/build_scene_assets.ps1`이 같은 크기의 투명 레이어와 `public/assets/images/scenes/registration.json`의 백분율 좌표를 만든다. 실행 화면은 생성된 등록 자료를 사용한다. 다섯 인물의 탐색용 자세와 클릭 윤곽은 [인물 배치 보정](CHARACTER_PLACEMENT.md)을 따른다.

기존 정의는 `services/image_selector.py`의 조사점·인물 배치·`DOOR_OUTLINES`, `registration.json`의 윤곽, `tools/build_scene_assets.ps1`의 추출 좌표에 나뉘어 있었다. 이번 변경에서는 원본 네 장의 구도에 맞춰 좌표를 다시 정의하고 기존 행동과 서버의 진행 조건을 유지한다.

## 배경과 레이어

- 보내준 네 PNG는 재생성·늘이기·잘라내기 없이 원본 바이트로 사용한다. 1·2·3호차는 같은 새 배경을 공유하고 인물과 조명 상태로 구분한다.
- 조사 대상 강조는 새 배경의 픽셀을 해당 윤곽에서만 추출한다. 이미지와 클릭 영역은 전체 원본 캔버스와 같은 원점·비율을 사용한다.
- 탐험가·노인은 기존 얼굴·복장을 유지한 새 앉은 자세, 청소원은 통로에서 걸레질하는 새 전신 자세를 탐색 화면에 사용한다. 승무원은 문턱에 발을 맞춘 전신 자세, 기관사는 중앙 운전석에서 뒤를 돌아보는 앉은 자세를 사용한다. 좌석·문턱·바닥 접촉·의자 가림·접촉 그림자·실내 조명을 원본 좌표에서 맞춘다.
- 인물 클릭 영역은 가려진 뒤의 불투명한 부분을 나누어 추적한다. 다리·지팡이·걸레·팔 사이 빈 공간과 접촉 그림자는 클릭 영역에서 제외한다. 탐색 중에는 배치된 캐릭터, 대화 중에는 기존 표정별 확대 초상화와 대화창을 사용한다.
- 작은 화면도 배경 전체를 원본 비율로 표시한다. 마우스 강조와 키보드 포커스는 같은 좌표를 사용하며 위치·크기를 확대하지 않는다.

## 생성과 확인

`tools/build_scene_assets.ps1`로 레이어를 다시 생성한다. 배경을 교체할 때는 PNG의 실제 크기와 `scene_layout.json`의 크기를 함께 수정한다. `tools/check_scene_registration.ps1`로 배경 추출 픽셀과 인물 레이어의 크기·윤곽을 확인한다. 퍼즐의 드래그·다이얼·최종 확인 동작은 별도 원본 퍼즐 화면을 유지하며 장소의 새 클릭 영역에서 연결한다.
