# 실제 모델 연결

원본 .env를 그대로 사용한다. 포함 변수는 OPENAI_API_KEY와 OPENAI_MODEL이며 파일 생성·복사·수정 단계가 없다. 원본 모델은 gpt-4o-mini다. 비어 있지 않은 프로세스 환경 변수가 있으면 원본 베이스와 같이 우선한다.

services/generator.py의 기존 DemoGenerator 클래스는 실제 OpenAI Responses API를 호출한다. 이름의 Demo는 원본 클래스명 보존을 위한 것으로, 데모 대화 모드가 아니다.

interpret는 입력의 의도·대상·수신자·부정·가정·외형 특징을 JSON Schema로 받는다. generate는 실제 모델로 해당 인물의 승인된 말머리를 선택하고, 서버 확정 대사와 결합해 기존 문자열 반환 계약을 유지한다. 단서·숫자·역명 등을 자유롭게 재서술하지 않으며 approved_reply가 승인 조합 외의 문장을 대체한다.

reasoning 또는 reasoning_effort 옵션을 보내지 않는다. store=False를 사용하고, 빈 응답·미완료·구조 오류·원문과 맞지 않는 해석을 검사한다. 외부 오류 원문·자격 증명은 사용자 응답과 로그로 전달하지 않는다.

의미 해석은 진행 권한이 아니다. 증거 지급·입장·퍼즐·마지막 시도와 엔딩은 GameEngine이 판단한다. API 장애가 난 자연어 턴은 상태를 확정하지 않는다. 실제 대화 품질은 모의 모델을 쓰는 단위 검사와 구분해 검수한다.
