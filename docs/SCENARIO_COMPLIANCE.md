# 시나리오 구현 기준

기준 문서: `종착역_없는_열차_주요_진행_루트_분기_설계서_표수정.docx` (v1.0, 2026-11-01).
원본 SHA-256: `00502B2A1C2452DA9B4531FDB647696B8233B552CD346A1C8BF9664759AD04CF`.
이 문서의 S01–S41, G01–G11, F1–F3와 T01–T18을 진행 규칙의 기준으로 사용한다.
선택지의 흐름과 효과는 기존에 제공된 상세 시나리오를 유지한다. 2026-11-02 제공된 인물 텍스트에 따른 성격·말투·배경 대사 변경은 [CHARACTER_SETTINGS.md](CHARACTER_SETTINGS.md)를 따른다. 그 텍스트의 엔딩·최종 탈출 규칙은 적용하지 않는다.

## 대화와 아이템

- S05–S11: 첫 인사는 되묻기이며 신문이나 도구를 주지 않는다. 사건/현재 상황 설명에서 신문을 전달한다. 다른 칸을 조사하겠다는 의사 또는 조사 제안 수락 이후에만 손전등과 안내서를 전달한다.
- 현재 선택지와 같은 뜻의 자유 입력은 `dialogue_choice_id`를 통해 같은 서버 이벤트로 연결한다. 현재 노드 이외의 선택지 ID는 거부하며 미래 단계로 이동하지 않는다.
- S15–S17 / T04: 노인의 외형 증언을 얻어야 한다. 각 독립 답변은 별도의 시도다. 바랜 종이만 말하면 휴지, 구멍만 말하면 영수증이며 두 부분 답변을 자동 합산하지 않는다. 두 특징을 한 설명으로 전달하면 승차권을 한 번 지급한다.
- 알려진 외형을 전달하며 “이런 승차권을 보셨나요?”라고 묻는 문장도 설명으로 판정한다. “구멍이 있나요?”처럼 모르는 특징을 묻는 문장은 확정하지 않는다. 외형 설명은 시나리오 선택지보다 먼저 판정하며, 입력창을 여는 선택지가 이미 작성된 설명을 가로채지 못한다.
- S18–S20: 승차권 내용을 확인하고 원본을 반환한 뒤 목적지 증언을 얻는다. 보관함에는 조사 기록이 남는다.
- S24–S26: 이상 현상 인정, 기관실 진입 필요성 설득/의뢰 제안, 의뢰 수락을 별도 상태로 관리한다.

## 장치와 보고서

- S28–S30: 안내서는 직접 열어야 하며 자동으로 보관함을 열지 않는다. 점검 덮개와 레버는 UI 조작 이벤트로만 움직인다. 채팅으로 조작을 말하면 방법을 안내한다.
- G07: 덮개를 열고 레버를 내리면 입실할 수 있다. 별도 손잡이 클릭은 필수 관문이 아니다. 입실 시 문 열림 상태를 기록한다.
- S31–S33: 책상/서류 조사에서 보고서를 발견하고 문서를 자동 표시한다. 발견/보유와 열람 완료는 분리한다. '보고서 내용 확인', 문서 닫기 또는 다른 문서로 이동하는 행동에서 `ack_document`를 처리한다. 그 전에는 보고서 제출로 기관실을 해금할 수 없다.
- 보고서를 펼친 상태를 서버가 확인한 경우에만 열람 완료를 승인한다. 다른 장소로 이동하거나 다른 문서를 바로 열면 이전 확인 권한은 만료된다.

## 최종 분기

- S37: 자기 승차권과 신문은 각각 독립적인 정답 증거다. 신문에 2026년 발행 정보를 표시한다. 제출한 문서의 읽음 상태만 갱신한다.
- F1/F2/F3: 잘못된 증거, 잘못된 제어 입력, 탈출 포기는 각각 전용 최종 확정에서만 BAD가 된다. 일반 대화나 탐색, 취소로는 기회를 쓰지 않는다.
- S39 / G10: 목적지는 `아지산역`, 비밀번호는 `2026`이어야 한다. 입력 앞뒤 공백만 제거하며 `아지산` 같은 축약은 정답으로 처리하지 않는다.
- S40–S41: 2026-11-05 사용자 요청에 따라 정답 입력의 최종 확정에서 즉시 GOOD과 엔딩 영상을 제공한다. 별도 하차 행동과 출입문/승강장 장소는 제거했다. 이전 정차 저장 기록도 GOOD으로 이어진다.

## 문서의 미확정 항목에 적용한 정책

최신 요청의 '엄격하게 적용'에 따라 문서에서 제안한 강한 게이트를 적용한다. 출발 시각은 23:59, 신문 발행 연도는 2026으로 통일한다. 안내서 열람과 노인 증언을 선행 조건으로 유지하고, 장치는 UI로만 조작한다. 새 세계관 사건이나 후일담은 추가하지 않는다. 이전 저장 기록은 삭제하지 않으며 변경된 규칙은 후속 행동부터 적용한다.

## 검증 위치

`tests/test_smoke.py`의 `DocumentRouteTest`는 인사/물품 인계 시점, 대화 노드 검증, 승무원 설득 순서, UI 전용 조작, 레버 이후 입실, 보고서 확인, 신문의 독립 증거 판정, 정답 확정 즉시 GOOD과 영상 제공, 출입문 없는 미니맵과 이전 정차 저장 기록의 호환을 검증한다. 기존 회귀 검사는 정석/대체 증거 GOOD, 각 BAD 분기, 부분 특징 재시도, 정전, 문서 열람과 아이템 중복 방지를 함께 검증한다.
