Created with the built-in `image_gen` tool using `transparent_background: true`. No CLI/API image generation was used. `public/assets/images/car1/background.png` supplied the existing walnut, moss-green curtains and amber lighting reference. The generated alpha is preserved: the aperture and exterior are transparent. The existing local window-loop video is live HTML behind the frame, with a subtle code-based glass reflection above it.

Video playback, keyboard/click retry and media cleanup remain independent of the decoration. This asset does not change scenery, dialogue, progression or the video file.
