# 배경과 상호작용 레이어

2026-11-08에 제공된 네 PNG를 원본 바이트로 적용한다.

| 배경 파일 | 제공 이미지 | 실제 크기 | 장소 |
| --- | --- | --- | --- |
| `../car1/background.png` | 열차 내부 | 1403×1121 | 1·2·3호차 공통 |
| `engine.png` | 기관실 | 1451×1084 | 기관실 |
| `crew.png` | 승무원실 내부 | 2464×1968 | 승무원실 |
| `crew-door.png` | 승무원실 외부 | 1344×896 | 4호차의 출입문 |

정의의 기준은 [`config/scene_layout.json`](../../../../config/scene_layout.json), 대상·진행 조건 설명은 [`docs/SCENE_INTERACTIONS.md`](../../../../docs/SCENE_INTERACTIONS.md)다. 이전 `car2.png`, `car3.png`는 과거 자산이며 현재 배경으로 사용하지 않는다.

`tools/build_scene_assets.ps1`이 정의 파일로부터 `registration.json`과 13개 투명 PNG를 만든다. 승무원실의 뒤쪽 기록철은 중복 상호작용이므로 등록과 레이어를 제거했다. 모든 레이어는 대응하는 배경과 같은 원본 크기와 원점을 유지한다. 좌표는 원본 픽셀에서 백분율로 변환되며, 화면 크기에 따라 같은 비율로 표시한다.

- `render_mode=background`: 안내문·창문·운행 서류·제어판·문 등 8개 조사 영역. 배경 픽셀을 해당 윤곽에만 복사한다. 브라우저는 같은 배경에 마스크를 적용해 강조한다.
- `render_mode=sprite`: 기존 캐릭터 5명의 별도 표시 레이어. 새 배경에 인물이 없으므로 탐색 중에도 표시한다. 좌석·책상에 가려지는 부분과 불투명한 인물 윤곽을 반영한다. 대화 중에는 기존 표정별 초상화로 전환한다.

다섯 인물은 `../characters/`의 탐색용 자세로 합성한다. `grounded` 등록은 톤·접촉 그림자·좌석/운전 의자 가림을 포함하고, `hit_path`는 2px 높이의 분리된 불투명 구간으로 SVG 클릭 영역을 만든다. 따라서 다리 사이·걸레 옆 빈 공간은 인물 대화를 가로채지 않는다. 승무원은 문 높이에 맞춘 전신 자세, 기관사는 운전석에 앉아 레버에 손을 뻗는 자세다. 생성 프롬프트와 최종 경로는 [인물 자산 기록](../characters/README.md)에 있다.

`tools/check_scene_registration.ps1`은 배경 추출 레이어의 원본 RGB·전체 캔버스 일치, 인물 레이어의 캔버스와 유효 알파 픽셀을 확인한다. `node tools/check_gameplay_ui.mjs --scenes-only --screenshots`는 실제 클릭·키보드 포커스·대화·보고서·퍼즐 연결·원본 비율·모바일 표시·정전을 확인한다.

문 이동은 같은 정의 파일의 `scenes.*.door`를 따른다. 서버가 실제 입장 조건을 통과한 목적지만 표시한다. 4호차 문은 잠금 해제 후 승무원실로, 승무원실 안의 문은 보고서와 출입 허가 확인 후 기관실로 연결한다. 기관실은 화면 안에 문이 없으므로 미니맵으로 되돌아간다.
