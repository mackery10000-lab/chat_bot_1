# 원본 배경과 강조 레이어

이번 대화에 첨부된 원본을 재생성하거나 리사이즈하지 않고 저장했다.

| 파일 | 첨부 이미지 | 용도 |
| --- | --- | --- |
| car3.png | 5번째 이미지, 청소원과 노인 | 3호차 |
| car2.png | 6번째 이미지, 앉아 있는 탐험가 | 2호차 |
| engine.png | 7번째 이미지, 도착역 장치 | 기관실 |
| crew.png | 8번째 이미지, 책상과 서랍 | 승무원실 내부 |
| crew-door.png | 9번째 이미지, 관계자 외 출입금지 | 4호차의 승무원실 출입문 |

`registration.json`은 각 투명 PNG의 원본 배경, 캔버스 크기, 윤곽 좌표와 클릭 영역을 함께 기록한다. 투명 PNG는 원본의 전체 크기와 원점을 유지하며, 보이는 픽셀은 원본과 동일하다. `tools/build_scene_assets.ps1`에서 다시 추출할 수 있다. 원본 첨부가 `.local/reference-*.png`에 없으면 이미 저장된 배경을 사용한다.

브라우저에서는 배경과 동일하게 샘플링한 원본에 PNG의 알파 마스크를 적용한다. 투명 이미지를 따로 축소할 때 생기는 경계 색 번짐을 방지한다. 강조는 별도 부모 레이어의 밝기와 발광으로 표현하며, 위치·크기·비율·변형은 바꾸지 않는다. 원본에 포함된 인물은 탐색 시 배경 속 윤곽으로 상호작용하고, 대화 시 기존 표정별 초상화를 사용한다.

`tools/check_scene_registration.ps1`은 모든 불투명 픽셀의 색과 원본 좌표 및 캔버스 크기를 검사한다. 배경을 교체할 때에는 해당 배경에서 마스크를 다시 추출하고, 등록 좌표와 브라우저 픽셀 비교도 함께 검증해야 한다.

문 이동 영역은 `services/image_selector.py`의 `DOOR_OUTLINES`에서 같은 배경의 전체 캔버스 백분율 윤곽을 사용한다. 서버가 현재 장소와 인접하고 `GameEngine.can_enter`를 통과하는 목적지만 전달한다. 대화 중, 어두운 3호차, 최종 확인 중, 엔딩에서는 이동 영역을 제공하지 않는다.

1·2·3호차의 보이는 문은 각각 다음 객차로 이동한다. 4호차의 문은 기존 등록 윤곽을 그대로 쓰며, 수동 개방을 마치면 항상 승무원실로 들어간다. 승무원실 안의 문은 보고서 확인과 실제 기관실 출입 허가를 모두 받은 경우 기관실로 들어간다. 연결은 `4호차 ↔ 승무원실 ↔ 기관실`이며, 허가를 받아도 문 목적지가 바뀌지 않는다. 이전 장소는 미니맵으로 돌아갈 수 있고, 기관실 배경에는 보이는 문이 없어 이동 영역을 추가하지 않는다.
